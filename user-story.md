# Patient Appointment Rescheduling System

## User Story

As a patient, I want to change my appointment time when I am not available, so that I can choose another suitable time.

## Acceptance Criteria

### Scenario: Rescheduling an appointment

**Given** the patient already has an appointment

**When** the patient wants to change the appointment to another available time

**Then** the system should update the appointment

**And** the patient should receive a confirmation

**And** the notification service should be informed about the change
